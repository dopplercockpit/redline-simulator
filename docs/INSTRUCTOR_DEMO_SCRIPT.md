# Redline Simulator: Flightpath CFO - 10-Minute Demo Script

## 1. Setup

- Open the Godot 4.5 project.
- Run the main scene.
- Enter the CFO Office.
- Keep this script and the Demo / QA shortcut handy: `Ctrl+Alt+D`.

## 2. Core Learning Promise

Flightpath CFO teaches finance judgment through a distressed regional airport. Players make weekly decisions, see ledger and cash consequences, answer boardroom questions, unlock tools, and review the run as an audit trail.

## 3. Demo Path

1. Open CFO Office.
2. Show laptop financials.
3. Open phone/inbox.
4. Explain action cards.
5. Press `Ctrl+Alt+D`.
6. Run Smoke Test.
7. Jump to Month 1 Complete.
8. Show Debt Desk.
9. Jump to Month 2 Complete.
10. Show Contract Review.
11. Jump to Month 3 Complete.
12. Show Audit Room.
13. Jump to Full Demo Complete.
14. Open Run Menu.
15. Open Run Review.
16. Export Summary.

## 4. What To Click

- Laptop: financial statements.
- Phone: weekly action cards and boardroom mission.
- Cabinet: Contract Review after unlock.
- TV: Audit Room after unlock.
- Painting/archive: Run Menu.
- `Ctrl+Alt+D`: Demo / QA panel.

## 5. What To Say

- "Every choice has a financial or control consequence."
- "The ledger is the source of truth."
- "Debt buys runway, but it adds pressure."
- "Contract terms matter because they create or block future recovery."
- "Compliance costs cash, but reduces uncertainty and audit pressure."

## 6. Discussion Prompts

- What is the difference between cash movement and revenue?
- When is debt useful and when does it become pressure?
- Why does a contract affect finance outcomes?
- Why does compliance cost money but reduce risk?
- What would you tell the board?

## 7. Suggested Student Assignment

Have students complete the Month 1-3 run, export the Markdown summary, and write a short board memo explaining cash survival, route incentive economics, contract governance, debt pressure, and audit posture.

## 8. Known Demo Shortcuts

- `Ctrl+Alt+D` opens Demo / QA.
- Demo states are deterministic fixtures, not simulation replays.
- Use Run Review to inspect the fixture timeline before exporting.
