# Patch 11 - Run Review Viewer + Instructor Demo Pack

## Purpose

Patch 11 adds an in-game Run Review panel so instructors and testers can inspect a completed or in-progress Month 1-3 Airport CFO run without reading raw save files.

## Run Review Panel

Run Review is opened from the Run Menu. It displays current cash, debt, points, audit score, operational risk, objectives, contract review results, Audit Room remediation, and a decision timeline.

## Decision Timeline

`GameManager.build_decision_timeline()` builds deterministic events from ledger transactions, completed missions, objective results, contract reviews, and Audit Room remediation. Timeline events are sorted by week and type.

## Export Preview

Run Review can preview the same Markdown generated by `RunSerializer.build_export_markdown()` without writing a file. Export Summary still writes `user://flightpath_run_summary.md`.

## Save Metadata

Run Menu now reads save metadata through `GameManager.get_save_metadata()`, including saved timestamp, week/month, points, audit score, risk, reputation, and demo target when present.

## Instructor Use

Use `Ctrl+Alt+D` to open Demo / QA, apply `full_demo_complete`, then open Run Menu > Open Run Review. This gives a complete local teaching review without replaying all 12 weeks.

## Known Limitations

The timeline is a review aid, not a full replay system. It summarizes stored state and ledger events; it does not reconstruct every UI interaction.
